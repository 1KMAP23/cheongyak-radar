# 판정 기준

판정은 3단계로 하고, 앞 단계에서 걸리면 뒤 단계는 참고로만 보여준다.

## 1단계: 신청 가능 여부 (자격)

공급 유형별로 우리 세대가 낼 수 있는지 먼저 거른다. 결과: `가능` / `경계` / `불가` / `확인 필요`.

| 항목 | 기준 |
|---|---|
| 세대주 요건 | 생애최초·노부모·일반 1순위(투기과열·청약과열)는 공고일 현재 세대주만 |
| 무주택 | 공고일 기준 세대 전원 무주택 |
| 청약통장 | 유형별 가입기간·납입횟수·예치금 (지역·면적별) |
| 소득 | 세대 월평균소득 ÷ 도시근로자 월평균소득(가구원수별, 2026: 2인 586만·3인 817만). 100% 이하면 모든 특공 소득 기준 통과, 100~130%는 공고문 확인, 130% 초과는 공공 특공 대부분 초과 |
| 거주 지역 | 신청자 기준. 같은 시·도 2년 이상이면 해당지역 우선. 다른 시·도는 대규모 택지면 기타지역 물량 |
| 특공 유형 | 신혼부부(혼인 7년 이내), 신생아(임신 중·2세 이하), 생애최초(평생 무주택·소득세 5년·세대주) |
| 민영 가점 | 무주택기간(만30세 또는 그 전 혼인일부터, 32점) + 부양가족(배우자·자녀·태아, 35점) + 통장 가입기간(17점) |
| 자산 — 공공분양 특공·60㎡ 이하 일반 | 부동산가액 + 자동차가액 각각 (2026: 2억1550만 / 4542만, 출산 1명 2억3705만 / 4996만) |
| 자산 — 신혼희망타운 | 총자산(부동산+금융+자동차+임차보증금-부채) 3억6200만 (출산 1명 3억9700만, 2명 4억3100만) |
| 자산 — 지분적립형 | 공고문 총자산 기준 |
| 자산 — 민영 특공 추첨분 | 소득 초과 시 부동산가액 3억3100만 |
| 자산 — 민영 일반, 공공 60㎡ 초과 일반 | 없음 |
| 재당첨 제한 | 세대원 과거 당첨 이력 |

자동차가액은 **공고일 기준 세대 보유 차량**의 시가표준액(행안부 기준가격 × 연식 잔가율). 공고일 이전 미등록 차량은 0. 기준 ±5% 이내는 `경계`.

자산 금액은 공고문 값 우선, 못 읽으면 `config/thresholds.json`.

## 2단계: 투자 판정

결과: `추천` / `조건부` / `비추천`.

### 안전마진 (가장 큰 비중)

- 비교 시세: 반경 1km(부족하면 2·3km), 준공 10년 이내, 전용 ±10㎡, 최근 6개월 매매 실거래 + 분양권 전매
- 단지별 ㎡당 중위가를 먼저 구하고 그 중위값을 씀 (거래 많은 한 단지가 시세를 끌고 가지 않게)
- 신도시·택지지구 블록(주소에 지구·블록, 또는 정확한 주소 없음)은 준공 **5년 이내 + 분양권**만 비교 (구도심과 급지가 달라서)
- 비교 표본 3건 미만이면 `불확실`, 비교 단지 1곳뿐이면 `표본 적음`
- 이상치 방어: 시세가 분양가의 1.6배 초과 또는 0.6배 미만이면 `시세 이상치` 표시하고 추천을 조건부로 낮춤
- 총비용 = 분양가 + 발코니·필수옵션 + 취득세 + 중도금 이자(추정)
- 실귀속 마진 = (비교 시세 − 총비용) × 귀속 비율 (지분적립형은 보유 지분, 신희타 모기지는 수익공유 차감)
- 2억 이상 → 추천 후보 / 1~2억 → 조건부 / 1억 미만·마이너스 → 비추천

### 가점·감점

| 구분 | 항목 |
|---|---|
| 가점 | 운행 중인 지하철역 도보 800m 이내 (예정역은 절반, 개통 예정 시기 표기) |
| 가점 | 초등학교 400m 이내 (초품아), 학원가 접근 |
| 가점 | 1000세대 이상 |
| 감점 | 300세대 미만, 나홀로 |
| 감점 | 미계약 잔여 반복 공급 (같은 단지 무순위·임의공급 3차 이상) = 미분양 신호 |
| 중립 | 계약취소분 무순위(최초 분양가) = 오히려 기회 |
| 리스크 | 실거주 의무, 전매제한, 재당첨 제한 기간 → 차익 실현 가능 시점 표기 |
| 리스크 | 주변 2년 내 입주 물량 |
| 리스크 | 필요 현금 vs 가용 현금, 단계별 자금 부족 경고 |

### 당첨 가능성

- 아내 가점·특공 조건으로 유형별 예상 경쟁 위치 표시
- 접수 후에는 경쟁률 API로 갱신

## 3단계: 출퇴근

- 오륜교회(강동대로 235)까지 카카오모빌리티 미래 길찾기
- 다음 월요일 08:00 출근 + 18:30 퇴근 시간 평균
- 30분 이내 `가능`, 30~45분 `애매`, 45분 초과 `불가`

## 종합

- ⭐ = 자격 `가능` + 투자 `추천` + 출퇴근 `가능`
- 자격 `불가`는 목록 하단 회색 처리 (숨기지 않음, 이유 표시)
- 모든 판정에 이유와 근거 수치를 함께 표시

## 누락 방지

- 소스: 청약홈(APT·무순위·임의공급·공공지원민간임대 제외) + LH 공고 + 뉴스 보조
- 매일 소스별 건수 기록, 전날 대비 급감 시 경고
- 청약홈 ↔ LH 교차 대조: LH 공고가 청약홈에 없으면 별도 표시
- 수집 실패 소스는 리포트 맨 위에 표시
