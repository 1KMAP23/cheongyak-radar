# 청약 레이더

매일 아침 수도권 청약·무순위·잔여세대 공고를 모아서, 우리 세대 기준으로 **신청 가능 여부 → 투자 판정 → 오륜교회 출퇴근**을 분석하고 아이폰 웹앱으로 푸시 알림을 보내는 개인용 앱.

## 구조

```
src/collect/   공식 API 수집기 (청약홈, LH, 국토부 실거래가, 카카오)
src/analyze/   자격·안전마진·입지·출퇴근 판정
web/           아이폰 홈 화면 웹앱 (목록, 단지별 분석 페이지, 공고문 링크)
config/        세대 정보 예시 (실제 값은 서버 .env / household.json, 커밋 금지)
docs/          판정 기준 문서
```

## 데이터 출처

| 출처 | 용도 | 비고 |
|---|---|---|
| 한국부동산원 청약홈 분양정보 (odcloud) | APT·신혼희망타운·무순위·잔여·임의공급, 주택형별 분양가, 공고문 링크 | 해외 IP 가능 |
| 한국부동산원 청약홈 경쟁률 | 경쟁률·특공 신청현황 | |
| LH 분양임대공고문 | 청약홈에 없는 LH 잔여세대·선착순 | 한국 IP 필요 |
| 국토부 아파트 매매 실거래가 상세 | 주변 신축 시세 | |
| 국토부 분양권전매 | 주변 분양권 시세 | |
| 카카오 로컬 | 좌표, 반경 지하철역·학교 | |
| 카카오모빌리티 미래 길찾기 | 월요일 08:00 출근 / 18:30 퇴근 예측 | |

## 실행

```
cp .env.example .env   # 키 입력
node src/run.mjs       # 수집 → 분석 → web/data 생성
```

키와 세대 정보는 저장소에 올리지 않는다.
